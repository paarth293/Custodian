# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/paarth293/custodian/security/advisories/new).

Include the affected component, steps to reproduce and the impact you expect.

## Response targets

| Stage           | Target                     |
| --------------- | -------------------------- |
| Acknowledgement | 24 hours                   |
| Triage          | 72 hours                   |
| Fix released    | 7 days for critical issues |

## Scope

Core, engine, agent, broker, ML host, desktop shell, AppContainer and sandbox
boundaries, IPC authentication, and offline data handling.

Placeholders listed in [`HONESTY.md`](HONESTY.md) are known gaps, not
vulnerabilities, though reports showing they are reachable in practice are welcome.
