# Custodian: four-minute project film

Format: 1920 x 1080, 24 fps, 16:9. Duration: exactly 04:00. English narration and captions.

This is an illustrated project explainer, not a live application recording. Current verified subsets and future scope are distinguished.

## 00:00–00:14 | THE IDEA

What if your computer could understand a task, carry it out, and show you proof? Meet Custodian: an offline Windows assistant built around a simple principle. Every supported action should be accountable.

## 00:14–00:28 | THE PROBLEM

Finding the right files, organizing a project, and checking every result takes time. Automation helps, but a confident answer is not evidence that your files are correct, or that your work is protected.

## 00:28–00:43 | MEET CUSTODIAN

Custodian brings those tasks into one conversation. Cubby is its on-screen companion. You describe the outcome, the local model proposes a supported plan, and native controls determine what can actually execute.

## 00:43–00:57 | OFFLINE BY DESIGN

An open-weight Qwen model runs on the computer. Supported local workflows do not need a cloud account or an upload. The model interprets the request; it does not receive unrestricted authority over Windows.

## 00:57–01:13 | FROM WORDS TO WORK

The request becomes a bounded program: discover, select, approve, execute, and verify. Native checks bind the plan to real locations and allowed operations. Unsupported or ambiguous requests must be refused or clarified.

## 01:13–01:30 | ILLUSTRATED FILE WORKFLOW

Consider a project handoff. Set a private location, then ask Custodian to copy the permitted project files to a chosen destination. Discovery can cover permitted local drives and ordinary folders, rather than just Documents or Downloads.

## 01:30–01:46 | ILLUSTRATED FILE WORKFLOW

Before the effect, a native approval preview identifies the selected files, destination, exclusions, and recovery behavior. Optional standing permissions support bounded routines. A changed source, a conflict, or missing authority prevents an unsafe substitution.

## 01:46–02:04 | ILLUSTRATED FILE WORKFLOW

Execution produces evidence, not just a success message. File identities and content checks help verify the result. The task retains receipts and progress. If a required check fails, that failure stays visible instead of becoming a completion claim.

## 02:04–02:21 | RECOVERY THAT RESPECTS YOUR WORK

For supported operations, receipts provide a path to undo and recovery inspection. If you edit an output afterwards, undo must preserve that later work. After an interruption, recovery inspects the evidence rather than blindly replaying effects.

## 02:21–02:37 | PRIVACY AND CONTROL

Private paths and protected locations are checked by native controls. Application exclusions provide a separate boundary for supported app workflows. Stop and revocation are execution controls. Document text and model suggestions cannot grant themselves permission.

## 02:37–02:56 | BEYOND FILE COPYING

The prototype also has narrow, version-qualified Visual Studio Code and Excel workflows. Native checks have exercised text editing, spreadsheet recalculation, save and reopen, source preservation, publication, and undo. These are specific adapters, not universal desktop control.

## 02:56–03:13 | BUILT FOR VERIFIABLE ACTION

A Tauri and React interface connects to a Rust execution core. Authenticated communication, supervised workers, deadlines, and durable journals support the boundary. The security claim is controlled, verified execution within supported scope, not immunity to every threat.

## 03:13–03:29 | SHOW THE EVIDENCE

Recorded checks include a twenty-nine-check desktop baseline, real editor and Excel workflows, and nine editor safety scenarios. These are measured subsets. They do not establish complete-product security, unrestricted automation, or finished installation acceptance.

## 03:29–03:48 | WHAT COMES NEXT

Next come stronger model reliability, repeated packaged validation, and clean offline installation. Archives, backup, document, and media workflows expand after native integration and verification. Laya remains experimental, not an active security control. Online capabilities remain future scope.

## 03:48–04:00 | CUSTODIAN

Custodian. Local intelligence. Verifiable action. A path back. Our ambition is broad. Our standard is evidence. Help us build an assistant people can trust with real work.
