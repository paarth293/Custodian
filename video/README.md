# Custodian video package

The production master is `CUSTODIAN-4MIN-EXPLAINER.md`; captions are in
`custodian-4min-explainer.vtt`.

This package is intentionally render-ready rather than pretending to contain a
finished MP4: the workspace does not currently include FFmpeg, source footage,
audio, or brand exports. To render the MP4 on a machine with FFmpeg, use the
timeline and render contract in the master script, then attach the generated
shots and voice/music tracks to the final composition.

The narration is 240 seconds by timeline, with scene timings designed for an
energetic but readable professional explainer. Claims were checked against the
current repository documentation and the known limitations are called out
explicitly.
