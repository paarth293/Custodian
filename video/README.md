# Project video source

The current four-minute Custodian film has been rendered and technically
verified at 1920 x 1080, 24 fps. Its reviewable source is in
[`custodian-explainer/`](custodian-explainer/):

- [`storyboard.json`](custodian-explainer/storyboard.json): chapter durations and narration.
- [`script.md`](custodian-explainer/script.md): readable script and chapter timings.
- [`captions.en.srt`](custodian-explainer/captions.en.srt): the matching English captions.

The local MP4, poster, audio, previews and one-off production renderer remain
under ignored `deliverables/custodian-film/`. They are local deliverables, not
application dependencies or files to push to Git. Existing local download paths
have been preserved. Publish media separately through the chosen release or
presentation channel when required.

The film uses the project's existing logo and Cubby artwork, local Windows
synthetic narration, and an original ambient score. Its application screens
are labeled illustrations. It separates verified subsets from unfinished
capabilities and is not product acceptance evidence.

The earlier proposed script and VTT were superseded by these actual production
sources and removed. Git history retains the old drafts; they are not the
transcript of the rendered film.
